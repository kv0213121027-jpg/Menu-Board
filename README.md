# 바다뷰 카페 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판**입니다.

종이 메뉴판을 새로 인쇄하지 않아도, 파일 안의 글자만 고치면 메뉴와 가격이 바로 바뀝니다.

---

## 무엇을 할 수 있나요

- 📱 휴대폰 화면(가로 390px 기준)에 딱 맞게 보입니다
- 🗂 **커피 / 논커피 / 디저트** 카테고리 버튼으로 골라 볼 수 있습니다
- ⭐ 사장님이 정한 메뉴에 **'사장님 추천'** 배지를 달 수 있습니다
- 🚫 다 팔린 메뉴는 **'오늘 품절'** 로 표시할 수 있습니다 (숫자 하나만 바꾸면 됩니다)
- 📞 **전화 걸기** 버튼을 누르면 손님 휴대폰의 전화 앱이 바로 열립니다
- 🖼 반투명 유리 느낌(글래스모피즘) 디자인, 배경 사진 위에 얹혀 있습니다

---

## 폴더 안에 무엇이 있나요

```
메뉴판/
├── index.html          ← 메뉴판 그 자체 (이 파일 하나가 전부입니다)
├── README.md           ← 지금 보고 계신 설명서
├── CLAUDE.md           ← 작업 규칙을 적어둔 메모
└── 샘플 사진/
    ├── 배경사진.png      ← 지금 쓰고 있는 배경 사진
    └── ChatGPT Image ... ← 예전에 쓰던 바다 사진 (안 씁니다)
```

**메뉴판은 `index.html` 파일 하나로 되어 있습니다.**
HTML(내용) · CSS(디자인) · JavaScript(동작)가 전부 이 한 파일 안에 들어 있어서,
설치할 것도 없고 복잡한 도구도 필요 없습니다.

---

## 어떻게 보나요

`index.html` 파일을 **더블클릭**하면 바로 열립니다.

컴퓨터에서 휴대폰 화면처럼 보고 싶다면:

1. 브라우저에서 **`F12`** 키를 누릅니다
2. 왼쪽 위의 **📱 휴대폰 모양 아이콘**을 클릭합니다
3. 위쪽에서 기기를 **iPhone 12 Pro** 등으로 고릅니다
4. 다시 `F12`를 누르면 원래대로 돌아옵니다

## 메뉴를 고치는 법

### 가장 많이 쓰는 것 — 메뉴 목록

**메뉴는 전부 파일 맨 위 한곳에 모여 있습니다.** 그 부분만 고치면 화면이 알아서 바뀝니다.

파일 위쪽에서 이렇게 생긴 부분을 찾으세요:

```
██   👇 [바꾸는 곳 4]  메 뉴 목 록   ← 여기만 고치면 됩니다!     ██
```

메뉴 한 줄은 이렇게 생겼습니다:

```js
{ 이름: '아메리카노', 가격: '4,800원', 설명: '고소한 원두', 추천: 0, 품절: 0 },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `'4,800원'` 에서 숫자만 바꾸기 |
| 이름·설명 바꾸기 | 작은따옴표 `' '` 안의 글자만 바꾸기 |
| 메뉴 추가하기 | 아무 줄이나 통째로 복사 → 아랫줄에 붙여넣기 → 글자만 바꾸기 |
| 메뉴 빼기 | 그 줄 전체를 지우기 |

### 배지와 품절 — **1은 켜짐, 0은 꺼짐**

전등 스위치라고 생각하시면 쉽습니다.

| 이렇게 쓰면 | 이렇게 됩니다 |
|---|---|
| `추천: 1` | ⭐ **사장님 추천** 배지가 붙고 카드가 강조됩니다 |
| `추천: 0` | 배지가 사라집니다 |
| `품절: 1` | 🚫 흐려지고 **오늘 품절** 이 뜹니다 |
| `품절: 0` | 원래대로 돌아옵니다 |

> 품절이어도 메뉴를 **지우지 마시고 숫자만 1로** 바꾸세요.
> 손님이 "이런 메뉴도 있구나" 하고 볼 수 있고, 다음 날 다시 `0`으로 되돌리면 됩니다.

### 배경 사진 바꾸기

새 사진의 이름을 **`배경사진.png`** 로 바꿔서 `샘플 사진` 폴더에 덮어쓰기만 하세요.
**코드는 한 글자도 안 건드려도 됩니다.**

## 고칠 수 있는 곳 전체 목록

파일 안에서 **`[바꾸는 곳`** 이라고 검색하면 전부 찾을 수 있습니다.

| 번호 | 무엇을 고치나 |
|---|---|
| **1** | 휴대폰 탭에 뜨는 이름 |
| **2** | 가게 색깔 (짙은 갈색 · 크림색) |
| **2-2** | 배경 사진 위 갈색 막의 진하기 |
| **2-3** | 배경 사진 파일 |
| **3** | 가게 이름 · 한 줄 소개 |
| **4** | ⭐ **메뉴 목록** (가장 많이 쓰는 곳) |
| **4-2** | 카테고리 버튼 높이 |
| **4-3** | 처음 들어왔을 때 선택될 카테고리 |
| **4-4** | 가격 글자 크기 |
| **4-5** | 배지 글자 (`사장님 추천` / `오늘 품절`) |
| **4-6** | 품절 메뉴가 흐려지는 정도 |
| **5** | 영업시간 · 전화번호 |
| **5-2** | 전화 걸기 버튼 높이 |
| **6** | 맨 아래 안내 문구 |
| **7-1** | '맨 위로' 버튼 크기 |
| **7-2** | '맨 위로' 버튼 안 글자 |

> ⚠️ **딱 두 가지만 조심하세요**
> 1. 작은따옴표 `'` 는 항상 앞뒤 짝이 맞아야 합니다
> 2. 줄 끝의 쉼표 `,` 를 지우면 안 됩니다
>
> 실수하셔도 괜찮습니다. 메뉴 대신 빨간 안내 상자가 뜨면,
> 방금 고친 줄의 따옴표와 쉼표만 다시 확인하시면 됩니다.

## 만든 방식

| 항목 | 내용 |
|---|---|
| 파일 구성 | `index.html` 한 파일 (HTML + CSS + JavaScript) |
| 사용한 도구 | 없음 — 리액트 같은 복잡한 도구를 쓰지 않았습니다 |
| 설치 | 필요 없음 — 파일을 더블클릭하면 바로 열립니다 |
| 글꼴 | 고운 돋움 → 없으면 맑은 고딕 |
| 디자인 | 글래스모피즘 (반투명 카드 · 부드러운 그림자 · 둥근 모서리) |
| 기준 화면 | 휴대폰 세로, 가로 폭 390px |

**휴대폰 대응**

- 가로로 돌려도 글자 크기가 깨지지 않습니다
- 아이폰 카메라 구멍(노치)에 글자가 가리지 않습니다
- 긴 메뉴 이름이 들어와도 가격이 찌그러지지 않습니다
- 버튼은 손가락으로 누르기 편한 크기입니다 (50px 이상)
