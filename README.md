# 브릿지 커피 디지털 메뉴판

손님이 휴대폰으로 보는 **디지털 메뉴판**입니다.

종이 메뉴판을 다시 인쇄하지 않아도, 파일 안의 글자만 고치면 메뉴와 가격이 바로 바뀝니다.
설치할 프로그램도, 배워야 할 도구도 없습니다.

---

## 무엇을 할 수 있나요

- 📱 휴대폰 화면에 딱 맞게 보입니다 (가로 390px 기준, 좁은 화면과 가로 화면도 확인했습니다)
- 🗂 **전체 / 커피 / 논커피 / 디저트** 버튼으로 골라 볼 수 있습니다
- 📌 스크롤을 아무리 내려도 **분류 버튼이 화면 맨 위에 붙어 따라옵니다**
- ⭐ 원하는 메뉴에 **'⭐ 사장님 추천'** 배지를 달 수 있습니다 (숫자 하나만 바꾸면 됩니다)
- 🚫 다 팔린 메뉴는 **'오늘 품절'** 로 표시됩니다 (메뉴를 지울 필요가 없습니다)
- 📞 **전화 걸기** 버튼을 누르면 손님 휴대폰의 전화 앱이 바로 열립니다
- 🥛 반투명 유리 느낌(글래스모피즘) 디자인

---

## ⚠️ 가장 먼저 하실 일 — 전화번호 바꾸기

지금 전화번호가 `000-000-0000` 으로 되어 있어서 **버튼을 눌러도 전화가 걸리지 않습니다.**

`index.html` 파일 아래쪽에서 이 두 줄을 찾아 실제 번호로 바꿔주세요. (두 곳 모두)

```html
<a class="전화버튼" href="tel:000-000-0000">📞 전화 걸기</a>
<p class="전화번호안내">000-000-0000</p>
```

## 폴더 안에 무엇이 있나요

```
메뉴판/
├── index.html          ← 메뉴판 그 자체 (이 파일 하나가 전부입니다)
├── README.md           ← 지금 보고 계신 설명서
├── CLAUDE.md           ← 작업 규칙을 적어둔 메모
└── 자료/
    └── 기획 시트.png    ← 처음 기획할 때 쓴 자료
```

**메뉴판은 `index.html` 파일 하나로 되어 있습니다.**
내용(HTML) · 디자인(CSS) · 동작(JavaScript)이 전부 이 한 파일 안에 들어 있습니다.

---

## 어떻게 보나요

`index.html` 파일을 **두 번 누르면(더블클릭)** 바로 열립니다.

**휴대폰에서 보고 싶을 때**
가장 쉬운 방법은 이 파일을 **카카오톡 '나에게 보내기'** 로 보낸 뒤 휴대폰에서 열어보는 것입니다.

**컴퓨터에서 휴대폰 화면처럼 보고 싶을 때**
브라우저 창의 오른쪽 가장자리를 마우스로 잡아 **좁게 줄이면** 휴대폰에서 보이는 모습과 같아집니다.

## 메뉴를 고치는 법

메뉴는 전부 파일 **맨 위 한곳**에 모여 있습니다. 그 부분만 고치면 화면이 알아서 바뀝니다.
파일을 열고 이렇게 생긴 표시를 찾으세요.

```
★★★ 여기가 메뉴를 고치는 곳입니다 ★★★
```

메뉴 한 개는 이렇게 딱 한 줄로 되어 있습니다.

```js
{ 이름: "아메리카노", 가격: "4,800원", 설명: "산미가 적은 고소한 원두", 추천: 0, 품절: 0 },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `"4,800원"` 에서 숫자만 고치기 |
| 이름 · 설명 바꾸기 | 큰따옴표 `" "` 안의 글자만 고치기 |
| 메뉴 추가하기 | 아무 줄이나 통째로 복사 → 아랫줄에 붙여넣기 → 글자만 고치기 |
| 메뉴 없애기 | 그 줄 전체를 지우기 (줄 끝 쉼표까지) |
| 잠깐만 숨기기 | 줄 맨 앞에 빗금 두 개 `//` 붙이기 → 다시 팔 때 `//` 만 지우기 |

### 배지와 품절 — **1은 켜짐, 0은 꺼짐**

전등 스위치라고 생각하시면 쉽습니다. 숫자 한 글자만 고치면 됩니다.

| 이렇게 쓰면 | 이렇게 됩니다 |
|---|---|
| `추천: 1` | ⭐ **사장님 추천** 배지가 붙고 카드가 금빛으로 도드라집니다 |
| `추천: 0` | 배지 없는 보통 메뉴가 됩니다 |
| `품절: 1` | 글자가 흐려지고 가격에 취소선이 그어지며 **오늘 품절** 이 뜹니다 |
| `품절: 0` | 원래대로 돌아옵니다 |

> 품절이어도 메뉴를 **지우지 마시고 숫자만 1로** 바꾸세요.
> 손님이 "이런 메뉴도 있구나" 하고 볼 수 있고, 다음 날 `0`으로 되돌리면 끝입니다.
> 숫자에는 따옴표를 붙이지 마세요. (⭕ `품절: 1` / ❌ `품절: "1"`)

### 분류(커피 / 논커피 / 디저트) 다루기

- 분류 이름을 바꾸려면 `분류: "커피"` 의 따옴표 안만 고치면 됩니다.
- 새 분류를 만드는 방법은 파일 안 `📦 분류를 통째로 새로 만드는 법` 부분에 예시가 있습니다.
- **분류를 새로 만들면 위쪽 버튼도 저절로 하나 더 생깁니다.**

## 그 밖에 고칠 수 있는 곳

파일 안에서 👇 표시를 찾으면 고칠 곳마다 한국어 설명이 붙어 있습니다.

| 무엇 | 어디 |
|---|---|
| 가게 이름 · 한 줄 소개 · 아이콘(☕) | 파일 아래쪽 `가게소개` 부분 |
| 영업시간 · 전화번호 | 파일 맨 아래 `가게정보` 부분 |
| 배지에 적히는 글자 | `추천배지글자` / `품절배지글자` |
| 가게 색깔 (짙은 갈색 · 크림색) | `🎨 색깔 모음` 부분의 색 코드 |
| 품절 메뉴가 흐려지는 정도 | `품절카드` 의 `opacity: 0.5` 숫자 |
| 카드 모서리 둥글기 | `메뉴카드` 의 `border-radius: 24px` 숫자 |

> ⚠️ **딱 세 가지만 조심하세요**
> 1. 큰따옴표 `"` 는 앞뒤 짝이 맞아야 합니다
> 2. 줄 끝의 쉼표 `,` 를 지우면 안 됩니다
> 3. 중괄호 `{ }` 와 대괄호 `[ ]` 도 지우면 안 됩니다
>
> 화면이 하얗게 나오면 방금 고친 줄의 따옴표 · 쉼표만 다시 확인하시면 됩니다.
> 되돌리기(Ctrl + Z)를 누르면 고치기 전으로 돌아갑니다.

## 휴대폰에서 확인한 내용

실제로 화면을 그려서 아래 네 가지를 확인했습니다.

| 확인한 것 | 결과 |
|---|---|
| 아이폰 크기 (390 × 844) | 글자가 잘리거나 화면 밖으로 넘치는 곳 없음 |
| 좁은 화면 (320 × 568) | 분류 버튼 4개가 모두 화면 안에 들어옴 |
| 가로로 돌렸을 때 | 깨지는 곳 없음. 가게 소개가 자동으로 작아져 메뉴가 더 빨리 보임 |
| 길게 스크롤할 때 | 분류 버튼이 화면 맨 위에 고정되어 따라옴 |

- 버튼 크기: 분류 버튼 52px, 전화 버튼 56px (손가락으로 누르기 편한 44px 이상)
- 본문 글자: 16px 기준
- 긴 메뉴 이름이 들어와도 가격이 찌그러지지 않습니다
- 아이폰이 전화번호를 파란 링크로 바꾸지 못하게 막아두었습니다

## 만든 방식

| 항목 | 내용 |
|---|---|
| 파일 구성 | `index.html` 한 파일 (HTML + CSS + JavaScript) |
| 사용한 도구 | 없음 — 리액트 같은 복잡한 도구를 쓰지 않았습니다 |
| 설치 | 필요 없음 — 파일을 두 번 누르면 바로 열립니다 |
| 글꼴 | 고운 돋움 → 없으면 맑은 고딕 |
| 디자인 | 글래스모피즘 (반투명 카드 · 부드러운 그림자 · 둥근 모서리) |
| 기준 화면 | 휴대폰 세로, 가로 폭 390px |
