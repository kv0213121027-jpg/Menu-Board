# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판 웹페이지**입니다.
파일은 `index.html` 하나뿐이고, 설치나 서버 없이 브라우저에서 바로 열립니다.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 누르면 해당 메뉴만 보입니다.
- **시그니처 메뉴**: 사장님 추천 메뉴에 배지를 달고 카드를 살짝 강조하며, 화면 맨 위에도 따로 보여줍니다.
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고 "오늘 품절"이 뜹니다.
- **전화 걸기 버튼**: 누르면 바로 전화 화면으로 연결됩니다.
- **매장 안내**: 영업시간, 휴무일, 주차, 좌석, 인스타그램 링크.
- **휴대폰에 맞춘 화면**: 폭 390px 기준이며, 가로로 돌려도 깨지지 않고, 길게 내리면 "맨 위로" 버튼이 나타납니다.
- **디자인**: 하늘색 파스텔과 크림색의 글래스모피즘 스타일(반투명 카드, 부드러운 그림자, 둥근 모서리), 글꼴은 고운 돋움(없으면 맑은 고딕).

## 보는 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 손님용 QR코드로 쓰려면 이 페이지를 인터넷 주소로 올려야 합니다. (예: GitHub Pages 같은 무료 호스팅)

> 고운 돋움 글꼴은 인터넷에서 불러옵니다. 인터넷이 없으면 맑은 고딕으로 대신 보입니다.

## 메뉴를 고치는 방법

메뉴 정보는 `index.html` **맨 위쪽의 "메뉴 정보" 칸**에 모여 있습니다. 거기만 고치면 화면이 저절로 바뀝니다.
자세한 안내는 그 칸의 한국어 주석에 적혀 있습니다. 메뉴 한 줄은 이렇게 생겼습니다.

```js
{ 이름: "아메리카노", 가격: 4500, 설명: "산미가 적은 고소한 원두", 시그니처: false, 품절: 0 },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `가격:` 뒤의 숫자만 바꿉니다. (원, 쉼표 없이 숫자만) |
| 이름·설명 바꾸기 | 큰따옴표 `" "` 안의 글자만 바꿉니다. |
| 메뉴 추가 | 같은 카테고리의 메뉴 한 줄을 복사해서 붙여넣고 내용을 바꿉니다. |
| 메뉴 삭제 | 그 메뉴 한 줄을 지웁니다. (줄 앞에 `//`를 붙이면 잠깐 숨기기) |
| 사장님 추천 달기 | `시그니처: true`로 바꿉니다. |
| 오늘 품절 켜기/끄기 | `품절: 0`을 `품절: 1`로 바꿉니다. 다시 `0`으로 바꾸면 판매 중입니다. |

> 줄 끝의 쉼표(`,`)와 큰따옴표가 하나라도 빠지면 화면이 비어 보일 수 있습니다.
> 고치기 전에 파일을 복사해서 백업해 두세요. 고친 뒤에는 새로고침(F5)으로 확인합니다.

가게 이름, 영업시간, 전화번호는 메뉴 정보 칸이 아니라 파일 아래쪽 화면 코드에 있습니다.
`Ctrl + F`로 "브릿지 커피", "08:00", "tel:"을 검색하면 찾을 수 있습니다.
(전화번호는 `tel:` 뒤의 숫자와 버튼 글자, 두 군데를 같이 바꿔야 합니다.)

## 색깔 바꾸기

`index.html`의 `<style>` 맨 위에 있는 색깔 설정(`:root`)의 `#` 숫자만 바꾸면 전체 색이 한 번에 바뀝니다.

## 파일 구성

```
메뉴판/
├─ index.html      메뉴판 전체 (HTML + CSS + JavaScript)
├─ CLAUDE.md       이 프로젝트를 AI와 함께 만들 때 지키는 규칙
├─ 자료/
│  └─ 기획시트.png   가게 정보와 메뉴를 정리한 기획 시트
└─ README.md       이 문서
```

## 가게 정보

- 가게: 브릿지 커피 (광주 북구 비엔날레)
- 소개: 매일 직접 볶는 스페셜티 커피
- 영업시간: 평일 08:00 ~ 21:00 / 주말 10:00 ~ 20:00 / 목요일 휴무
- 전화: 062-000-0000 (예시 번호이므로 실제 번호로 바꿔 사용하세요)
