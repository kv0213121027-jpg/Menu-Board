# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR코드를 찍으면 휴대폰으로 보게 되는 **디지털 메뉴판 웹페이지**입니다.
파일은 [`index.html`](index.html) 하나뿐이고, 설치나 서버 없이 브라우저에서 바로 열립니다.

## 주요 기능

- **카테고리 버튼**: 전체 / 커피 / 논커피 / 디저트. 처음에는 "전체"가 선택돼 있고, 누르면 해당 메뉴만 보입니다.
- **사장님 추천 배지**: 지정한 메뉴에 배지를 달고 카드를 살짝 강조합니다. (지금은 아인슈페너, 흑임자 라떼)
- **오늘 품절 표시**: 품절 메뉴는 흐리게 보이고 "오늘 품절" 도장이 찍힙니다.
- **영업시간과 전화 걸기**: 맨 아래에 영업시간이 있고, 전화 걸기 버튼을 누르면 바로 전화 화면으로 연결됩니다.
- **휴대폰에 맞춘 화면**: 폭 390px 기준이며, 작은 폰(360px 이하)과 가로로 눕힌 화면에서도 깨지지 않습니다. 아래로 많이 내리면 "맨 위로" 버튼이 나타납니다.
- **디자인**: 칠판에 분필로 쓴 빈티지 카페 메뉴판 스타일. 나무 액자, 색분필 카드, 손글씨 글꼴(개구, 나눔펜), 떠다니는 분필 가루가 있습니다. 대표 색은 짙은 갈색(`#4A3728`)과 크림색(`#F5EFE6`)입니다.

## 보는 방법

1. 이 저장소를 내려받습니다.
2. `index.html` 파일을 더블클릭하면 브라우저에서 열립니다.
3. 손님용 QR코드로 쓰려면 이 페이지를 인터넷 주소로 올려야 합니다. 이 저장소는 GitHub Pages로 열면 설명서가 아니라 메뉴판 화면이 바로 나옵니다. (`index.html`이 저장소 맨 위에 있기 때문입니다)

> 손글씨 글꼴은 인터넷에서 불러옵니다. 인터넷이 없으면 고운 돋움, 그것도 없으면 맑은 고딕으로 대신 보입니다.

## 메뉴를 고치는 방법

메뉴 정보는 `index.html` **맨 위쪽의 `menuData` 칸**에 모여 있습니다. 거기만 고치면 화면이 저절로 바뀝니다.
자세한 안내는 그 칸의 한국어 주석에 적혀 있습니다. 메뉴 한 줄은 이렇게 생겼습니다.

```js
{ name: "아메리카노", price: "4,500원", desc: "산미가 적은 고소한 원두", pick: 0, soldOut: 0 },
```

| 하고 싶은 일 | 방법 |
|---|---|
| 가격 바꾸기 | `price:` 뒤 따옴표 안의 글자만 바꿉니다. (예: `"4,800원"`) |
| 이름·설명 바꾸기 | 큰따옴표 `" "` 안의 글자만 바꿉니다. |
| 메뉴 추가 | 같은 카테고리의 메뉴 한 줄을 복사해서 붙여넣고 내용을 바꿉니다. 줄 끝 쉼표(`,`)를 빼먹지 마세요. |
| 메뉴 삭제 | 그 메뉴 한 줄을 통째로 지웁니다. |
| 사장님 추천 켜기/끄기 | `pick: 0`을 `pick: 1`로 바꿉니다. 다시 `0`으로 바꾸면 꺼집니다. |
| 오늘 품절 켜기/끄기 | `soldOut: 0`을 `soldOut: 1`로 바꿉니다. 다시 `0`으로 바꾸면 판매 중입니다. |
| 카테고리 추가·이름 변경 | `title:` 글자를 바꾸거나, 파일 안 "새 카테고리 예시"를 복사해 붙입니다. 위쪽 버튼은 자동으로 생깁니다. |
| 배지·도장 글자 바꾸기 | `PICK_LABEL`(사장님 추천), `SOLDOUT_LABEL`(오늘 품절)의 따옴표 안 글자를 바꿉니다. |

바꾼 뒤에는 저장(Ctrl+S)하고 브라우저를 새로고침하면 바로 반영됩니다.
화면이 비거나 메뉴가 안 나오면 쉼표나 따옴표가 빠졌는지 먼저 확인해 보세요.

## 가게 정보 고치는 방법

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 가게 이름·한 줄 소개 | `<header>` 안의 글자 |
| 영업시간 | `<footer>` 안의 영업시간 목록 |
| 전화번호 | 전화 걸기 버튼의 `href="tel:..."` 숫자와 버튼 글자 |
| 색깔 | `<style>` 맨 위 `:root`의 `#`으로 시작하는 색 숫자 |
| 분필 거칠기 | `scale="1.5"` 숫자 (클수록 거칠어집니다) |

## 폴더 구성

```
메뉴판/
├─ index.html        메뉴판 화면 (이 파일 하나가 전부입니다)
├─ README.md         이 설명서
└─ 자료/
   ├─ CLAUDE.md      이 프로젝트를 만들 때 지킨 규칙
   └─ 기획시트.png    가게 정보와 메뉴 기획서
```

## 만든 방식

HTML, CSS, JavaScript만 `index.html` 파일 하나에 담았습니다. 리액트 같은 별도 도구는 쓰지 않았고, 화면의 모든 글자는 한국어입니다.
